# CodeEval
A benchmark harness for AI coding agents — sends ML coding tasks to Claude and GPT, then auto-grades every submission via pytest on correctness, efficiency, and edge-case handling. Surfaces side-by-side model comparisons so failure patterns don't hide. Built with FastAPI + Docker for repeatable, no-drama runs.
